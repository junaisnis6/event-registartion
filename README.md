# Eventify – Event Registration System

## Live Demo
https://junaisnis6.github.io/event-registartion/

## Overview
Eventify is a web-based event registration system built using HTML, CSS, JavaScript, and Firebase.  
It allows users to register for events, login securely, and provides an admin dashboard to manage event data.

## Features
- User Registration and Login using Firebase Authentication
- Admin Login Panel
- Event Registration System
- Admin Dashboard for managing events
- Firebase Firestore database integration
- Responsive UI design
- Hosted using GitHub Pages

## Firebase Setup
1. Create Firebase project
2. Enable Authentication (Email/Password)
3. Enable Firestore Database
4. Add Firebase config in your project

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  appId: "YOUR_APP_ID"
};
